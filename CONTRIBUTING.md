# Contribuindo com o Threeebs :3

Obrigado pelo interesse no projeto.

## Issues

Antes de abrir uma Issue:

1. verifique se o problema já foi relatado;
2. use um título curto e descritivo;
3. informe os passos para reproduzir;
4. descreva o resultado esperado e o resultado obtido;
5. remova dados pessoais, tokens e informações privadas.

## Pull Requests

Mantenha cada Pull Request pequeno e relacionado a um único objetivo. Explique o motivo da mudança e como ela foi validada.

Contribuições aceitas podem ser adaptadas no fluxo oficial de desenvolvimento antes de aparecerem em uma release pública. A referência e a autoria da contribuição devem ser preservadas.

Não envie vulnerabilidades por Pull Request ou Issue pública. Consulte `SECURITY.md`.
