# Segurança

## Relatando uma vulnerabilidade

Não publique vulnerabilidades exploráveis em Issues, Discussions ou Pull Requests.

Use a opção privada **Report a vulnerability** na aba Security, quando disponível. Caso ela não esteja disponível, contate o responsável pelo projeto por um canal privado.

Inclua somente o necessário:

- descrição do problema;
- impacto possível;
- passos seguros para reprodução;
- versão afetada;
- sugestão de correção, se houver.

Nunca inclua credenciais reais, dados pessoais ou dados de produção.

## Segredos expostos

Uma credencial publicada deve ser considerada comprometida e revogada ou rotacionada imediatamente. Apenas remover o arquivo não é suficiente.
